## 🚀 DEEDOX AI Dev Workspace v1.0.0 — Official Launch Edition

DEEDOX AI Dev Workspace is a sovereign local desktop IDE engineered on Electron 34, React 19, and Vite. Features the automated Pulse Dev process watchdog, a 7-persona collaborative 3D AI roundtable, and 1-click self-healing error diagnosis.

### 📦 Windows Binaries:
* **DEEDOX-AI-Dev-Workspace-Setup-1.0.0.exe** — Full Windows Installer (x64) with auto-desktop shortcut & registry registration.
* **DEEDOX-AI-Dev-Workspace-Portable-1.0.0.exe** — Portable Standalone Edition (No installation required).

### ⚡ Highlights:
* **Pulse Dev Watchdog:** Real-time port listening, process heartbeat, and memory guard.
* **Autonomous 3D Multi-Agent Roundtable:** 7 collaborative AI agents with specialized software development roles.
* **Sovereign Local-First Architecture:** Complete privacy with local workspace isolation.
