MODULE 01 • DESKTOP LAUNCHPAD

Mobile Squircle App Drawer & Real-Time Port Sniffing

Instead of an endless list of cluttered text lines, AI Dev Workspace models your repositories as native squircle desktop apps (inspired by macOS Launchpad and iOS).

  • ✓
    Automatic Tech Stack Recognition: Inspects root files to identify Vite, React, Next.js, Express, FastAPI, Django, Cargo (Rust), and Go, applying signature framework icons automatically.
  • ✓
    Sub-Second Port Sniffing: Actively monitors child process stdout to capture allocated TCP sockets (e.g. localhost:5173) and exposes a 1-click in-app or browser launch button.
  • ✓
    Live Status & Elapsed Timers: Running projects pulsate with emerald rings and display active running timers (e.g. 02:14 :5173 ↗).

Standard Electron webviews discard cookies upon process teardown. DevWorkspace registers a persistent partition storage root, retaining cookies, tokens, and IndexedDB indefinitely.
MODULE 02 • PERSISTENT HYBRID APPS

NovaWeb Architecture: Never Log In Twice

Convert your most essential SaaS and developer tools into native desktop mini-apps. ChatGPT Plus, Claude 3.7, GitHub, Linear, and Notion run in dedicated sandboxes right next to your servers.

  • ✓
    Zero Session Eviction: Sessions survive OS reboots, app updates, and memory garbage collection.
  • ✓
    Automatic Metadata Scraping: Enter any URL (e.g. https://linear.app); DevWorkspace scrapes high-res favicons and title metadata in milliseconds.
  • ✓
    Isolated Multi-Profiles: Work accounts and personal accounts stay safely partitioned with zero cross-contamination.
MODULE 03 • HIGH-SPEED REPO DISCOVERY

Recursive Drive Scanner (C:\, D:\, E:\)

Finding where you cloned repos across multiple hard drives used to mean hunting through folders. DevWorkspace scans entire physical drives in under 3 seconds.

  • ✓
    Intelligent Directory Pruning: Automatically skips black holes like node_modules, .next, .git, venv, and target to prevent slow scans.
  • ✓
    Multi-Ecosystem Detection: Matches package.json, requirements.txt, pyproject.toml, Cargo.toml, and go.mod.
  • ✓
    1-Click Bulk Import: Instantly add dozens of repos into your squircle launcher without manual configuration.

MODULE 04 • SELF-HEALING RUNTIME

xterm.js ANSI Terminal & 1-Click AI Error Solver

Nothing kills developer momentum like an unexpected port collision or broken dependencies. AI Dev Workspace pairs a native ANSI terminal with OpenRouter AI diagnostics.

  • ✓
    Full ANSI Color Support: Beautiful syntax highlighting for npm, pnpm, yarn, cargo, python, and docker streams.
  • ✓
    Error Pattern Detection: Automatically flags crashes, missing modules, out-of-memory errors, and EADDRINUSE port conflicts.
  • ✓
    1-Click Surgical Fix: Generates exact CLI repair commands and executes them directly into the terminal stream upon confirmation.
