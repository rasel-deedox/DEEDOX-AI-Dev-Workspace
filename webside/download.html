Installation & Security FAQ

Because AI Dev Workspace is a newly released independent open-source release, Microsoft SmartScreen hasn't built an automatic reputation metric yet. Click "More info" and then "Run anyway". The binary is completely safe, zero-telemetry, and verified clean.
AI Dev Workspace bundles its own internal Electron/Node 22 runtime for workspace tasks and terminal emulation. However, to execute your own project commands (e.g., npm run dev or uvicorn main:app), you'll want your typical language CLIs installed on your system PATH.
The Portable edition creates zero registry keys, requires no administrator privileges, and stores configuration locally inside the executable directory. The Setup installer adds Start Menu shortcuts and supports automatic updates.
